# CSC584 - Individual Assignment 1: Personal Profile Web Application

## Project Description
This project is a simple Personal Profile Web Application developed for the CSC584 Individual Assignment. It allows users to enter their personal information through an HTML form and displays the submitted information on a JSP page.

## Technologies Used
*HTML
*CSS
*Java Servlet
*JSP
*Java
*NetBeans IDE
*GlassFish Server

## Features
*Collects personal information through an HTML form.
*Processes submitted information using a Java Servlet.
*Displays the submitted information on a JSP page.
*Provides a simple and user-friendly interface.

## How to Run the Application
1. Download or clone this repository. 
2. Open **NetBeans IDE**.
3. Go to **File** -> **Open Project** and select this project folder.
4. Choose the downloaded **PersonalProfileApp **project folder.
5. Right-click the project and select **Clean and Build**.
6. Right-click the project and select **Run** to launch the application in your default web browser.
